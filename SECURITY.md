# Security Policy

## Supported versions

Security fixes are provided for the latest stable JACIS release. Older releases are not routinely patched; please upgrade before reporting an issue when practical.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull requests. Email [jan@wiemer.nrw](mailto:jan@wiemer.nrw), the security contact listed in the [Code of Conduct](CODE_OF_CONDUCT.md). Include the affected version, impact, and steps to reproduce where safe to do so. Please allow time for the maintainers to investigate before making details public.
